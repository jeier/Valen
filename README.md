# Valen

Site da Valen — gastronomia autoral por delivery em Colombo/PR.

Site estático (HTML + CSS + JS, sem etapa de build), publicado na Vercel.

- `index.html` — início (chamada, benefícios, antes e depois)
- `cardapio.html` — cardápio por categorias, cada prato abre o WhatsApp
- `blog/` — lista de posts e artigos
- `contato.html` — contato e encomendas
- `assets/` — logo, estilos e scripts
